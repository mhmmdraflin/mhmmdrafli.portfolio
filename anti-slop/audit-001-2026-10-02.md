# Antislop Audit Report (001)
**Date:** 2026-10-02

Here is the audit of the current project based on the antislop guidelines. Please review the findings below and reply with the numbers you would like me to fix.

1. **[HIGH] R-32 Keyboard Accessibility**
   Reason: The main "MRN." logo in `Header.jsx` uses a `<span>` with `onClick` but lacks a `tabIndex` and keyboard event handler (`onKeyDown`), meaning keyboard-only users cannot navigate back to the home section.
2. **[HIGH] R-32 Keyboard Accessibility**
   Reason: Certificate cards in `CertificatesSection.jsx` use `<div onClick={...}>` without `tabIndex="0"` or keyboard event handlers, making the lightbox modal unreachable for keyboard users.
3. **[HIGH] R-32 Keyboard Accessibility**
   Reason: Custom interactive elements (like the Language Switcher and Theme Toggle buttons in `Header.jsx`) rely on default browser focus outlines which are often removed or insufficient; they need explicit, visible focus states.
4. **[MEDIUM] R-10 Glassmorphism**
   Reason: Extensive use of heavy blur effects (`backdrop-blur-24px`, `backdrop-blur-16px`, `backdrop-blur-[20px]`) across multiple components (Header, Ecosystem, Timeline). Needs a verified purpose check to ensure it's an accent, not a default covering everything.
5. **[MEDIUM] R-07 Background / R-13 Glow**
   Reason: The `index.css` defines an `.ambient-blob` class with an 80px blur, which is a common generic AI decoration pattern (colored glow background) without a stated hierarchy purpose.
6. **[LOW] R-19 Animations**
   Reason: Generic template animations like `animate-fade-in-up` are used as default section entrances (e.g., in `ProjectsSection.jsx`), and `animate-float` on the project mockups, without a documented UX purpose.
